# Tec-flow

Sistema de gestión de tickets técnicos para registro, seguimiento y resolución de solicitudes.

## Descripción

Proyecto desarrollado siguiendo un proceso formal de Ingeniería de Software, con fases documentadas de planificación, análisis, diseño, implementación, pruebas y despliegue.
