## Resumen ejecutivo

- **Proyecto:** Tec-flow — aplicación web académica de gestión de tickets.
- **Tipos de ticket:** soporte técnico, incidentes/bugs, mantenimiento físico.
- **Roles:** Usuario, Agente, Administrador.
- **Plazo:** ~1 mes (6 semanas con pruebas y despliegue).
- **Presupuesto:** USD $0–5 (herramientas gratuitas).
