## Resumen

- **21 requisitos funcionales** en 5 módulos (auth, tickets, catálogos, reportes, notificaciones).
- **15 requisitos no funcionales** (seguridad, rendimiento, usabilidad, datos).
- **3 roles** y **3 tipos de ticket**; ciclo de vida Abierto → En proceso → Resuelto → Cerrado (+ Cancelado).
- **15 reglas de negocio** que rigen transiciones, permisos y auditoría.
