# Tec-flow — Recursos y Presupuesto

## Recursos humanos

| Recurso | Dedicación estimada |
|---------|---------------------|
| Desarrollador principal (estudiante) | Dedicación continua durante 6 semanas |
| Docente / asesor | Revisiones semanales (1–2 h) |

## Recursos técnicos

| Recurso | Uso | Costo estimado |
|---------|-----|----------------|
| PC de desarrollo | Código, pruebas locales | $0 (propio) |
| GitHub (repositorio privado) | Control de versiones y documentación | $0 (plan gratuito) |
| Stack de desarrollo | Frontend, backend y base de datos | $0 (tecnologías de código abierto; a definir en diseño) |
| Hosting de despliegue | Aplicación web en línea | $0–$5 USD/mes (plan gratuito o mínimo de proveedor como Railway, Render o Vercel) |
| Base de datos en la nube (si aplica) | Datos del sistema | $0 (tier gratuito) |

## Presupuesto total estimado

**USD $0 – $5** (proyecto académico apoyado en tier gratuito de herramientas).

## Supuestos

- No se compran licencias; se usa software libre.
- No se requiere dominio personalizado (se usa el subdominio del proveedor); si se necesita, agregar ~$10 USD/año.
- Los datos iniciales (usuarios de prueba, catálogos) se cargan como semillas (seed).
